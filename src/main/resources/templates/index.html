Enterprise Medical Records Architecture

Designed to solve fragmented patient histories through cloud-native synchronization and secure file dispatching.

Cloud Object Storage

Diagnostic PDFs, radiology imaging, and laboratory results are streamed directly to Supabase cloud storage buckets with cryptographic integrity.

Strict Role Separation

Granular authorization pipelines isolate patient personal vaults from practitioner clinical reviews, governed by Spring Security session controls.

Managed Relational Database

All patient profiles, clinical metadata, and diagnostic records are normalized in Supabase PostgreSQL with ACID transaction guarantees.

Standardized Categorization

Typed classification for Lab Reports, Prescriptions, X-Rays, Diagnostic Scans, and Discharge Summaries with instant search and filtering.

Clinician Case Sheet View

Registered medical practitioners can browse patient rosters, inspect clinical histories, and securely view uploaded patient medical files.

Cryptographic Credentials

Passwords hashed via BCrypt with 12 salt rounds. Secure authenticated session tokens protect against unauthorized URL tampering.

Cloud Engineering Stack

Integrated Java & Cloud Service Topology

This project satisfies academic and enterprise specifications by decoupling compute, data persistence, and unstructured file storage across dedicated cloud layers:

Compute Layer (Render Cloud)

Containerized Spring Boot 3 web service executing in an isolated Linux container with automated health scanning.

Persistence Layer (Supabase PostgreSQL)

Hosted in Asia-Pacific with PgBouncer connection pooling on port 5432, managing relational entity graphs.

Storage Layer (Supabase Cloud Storage)

Dedicated S3-compliant bucket medical-records with secure multipart streaming via REST endpoints.

Service Architecture Breakdown
  • Backend Framework Spring Boot 3.2.5 (Java 17)
  • ORM & Data Access Hibernate 6 / Spring Data JPA
  • Template Rendering Thymeleaf + Bootstrap 5.3
  • Cloud Hosting Provider Render Web Services
  • Cloud Database Host Supabase Pooler (ap-northeast-1)
  • Container Packaging Multi-Stage Dockerfile

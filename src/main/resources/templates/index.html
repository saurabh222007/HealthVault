HealthVault Cloud is a secure, role-based platform for patients and doctors to store, manage and share medical records — powered by Java Spring Boot and deployed on cloud infrastructure.

Why HealthVault Cloud?

Cloud Storage

Upload lab reports, prescriptions, X-rays, and scans securely to cloud storage. Access from anywhere.

Role-Based Access

Separate dashboards for Patients and Doctors. Each user sees only what they're authorized to view.

Secure & Private

BCrypt password hashing, Spring Security authentication, and encrypted cloud storage for all files.

Record Categories

Organize records by type: Lab Reports, Prescriptions, X-Rays, Scans, Vaccinations and more.

Cloud Database

All patient data stored in a managed cloud PostgreSQL database — no local storage needed.

Responsive UI

Works seamlessly on desktop, tablet, and mobile. Built with Bootstrap 5 for a modern look.
